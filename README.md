# hostile website 

## How to run it

1. Open this folder in VS Code.
2. Click **Go Live** (bottom right).
3. Start at `index.html`.

### The pages

| Page | File | What happens |
| --- | --- | --- |
| Lobby | `index.html` | waiting area for forms |
| Form 27-A | `form-a.html` | form A|
| Form 27-B | `form-b.html` | form B |
| Processing | `meat-processing.html` | meat 
| Appeal | `appeal.html` | dead end |

## Seeing it fresh

To visit as a first-timer again, open the browser console
(Cmd+Option+J) and run `localStorage.clear()`.

Built with [p5.js](https://p5js.org) 2.3.4.
